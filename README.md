🤖 AI-Agent

An AI Agent system designed to support multiple tasks using specialized agent teams and structured instructions.

📌 About the Project

AI-Agent is a multi-agent based project that organizes different tasks through specialized teams. Each team is designed for a particular purpose, allowing the system to handle tasks in a structured and efficient way.

The project includes different datasets, agent configurations, instructions, and Python files that work together as part of the AI Agent system.

✨ Features

- 🤖 AI Agent-based task handling
- 👥 Multiple specialized agent teams
- 📝 Structured instructions for agents
- 📊 Dataset-based processing
- 🔍 Code review support
- ✍️ Writing-related task support
- 🎓 Education-related task support
- ⚙️ Configurable agent systems

 📂 Project Structure

| File | Description |
|------|-------------|
| `asi.py` | Main Python component of the AI Agent system |
| `dr1.py` | Python module used in the project |
| `agent_systems.json` | Configuration/details of the agent systems |
| `instructions.txt` | Instructions provided to the agents |
| `Code_Reviewer.csv` | Dataset related to code review |
| `dev_team.csv` | Developer team dataset |
| `edu_team (1).csv` | Education team dataset |
| `mark_team.csv` | Marketing team dataset |
| `writing_team.csv` | Writing team dataset |

 🛠️ Technologies

- Python
- JSON
- CSV
- AI / Agent-based systems

🎯 Objective

The main objective of this project is to explore how AI agents and specialized teams can be organized to perform different tasks efficiently using structured data and instructions.
